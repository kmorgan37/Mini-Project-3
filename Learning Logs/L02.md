## Iteration 2 Learning Log

**How did you connect user input to API calls?**

Each mode card on the home screen calls `startGame(mode)` on click, which sets
the game state and triggers `loadRound()`. Inside `loadRound()`, the mode stored
in state determines which API gets called and which hardcoded pool gets used.
The tricky part was making sure the entire UI — buttons, colors, messages,
progress bar — reset cleanly between rounds without anything carrying over.

**What CSS layout did you use for displaying data?**

CSS Grid for both the home screen mode cards and the two answer buttons, with
`clamp()` for font sizes so text scales naturally across screen sizes. I added
media query breakpoints at 850px for tablet and 500px for mobile, and switched
the grids from two columns to one column on smaller screens.

**What design decisions did you make?**

The main decision was putting the quote on a bright white card against a very
dark background — it makes the quote the focal point and gives the reveal moment
more visual contrast. I also switched the mode title font to Inter for better
readability, and added a progress bar in the game header so players always know
how far into the game they are.
