## Iteration 1 Learning Log

**What does the API response look like? What fields did you use?**

The two APIs return data in completely different formats. `kanye.rest` returns a
simple object: `{ quote: "..." }` — just one field, easy to grab. The Quotable
API was trickier: depending on which endpoint you hit, it returns either a single
object or an array, both with `content` and `author` fields. I had to console.log
the response to figure out what I was actually working with before I could use it.

**What was the trickiest part of getting fetch to work?**

Understanding that `await` only works inside an `async` function. Once that
clicked, the rest made more sense. The other confusing part was that you need
two separate awaits — one for the fetch itself, and one to parse the response
body as JSON.

**If AI helped, what did it explain about async/await?**

AI helped explain why fetch is two steps: the first await waits for the server
to respond, and the second await waits for the response body to fully load and
parse. Before that I thought one await would handle everything.
