## Iteration 3 Learning Log

**What extension did you add?**

Two extensions: localStorage tracking to prevent the same quotes from repeating
across multiple games, and a per-session deck system that pre-shuffles and deals
quotes uniquely so you never see the same quote twice in one 8-round game.
I also added an exit button in the game header so players can quit mid-game and
return to the mode select screen.

**What edge cases did you handle?**

The hardest one was a 50/50 distribution bug — in some modes, all 8 rounds were
pulling from the same source, making the correct answer obvious every time. I
fixed it by pre-building the round deck with exactly 4 quotes from each side
before the game starts, rather than deciding randomly each round. I also handled
API failures with graceful fallbacks so the game never crashes mid-round.

**What surprised you about working with a real API?**

How unpredictable API responses can be. The format changes between endpoints,
requests sometimes fail with no clear reason, and the data doesn't always come
back the way you expect. Building solid fallbacks ended up being just as
important as writing the actual fetch call. I made a lot of progress on the
quote redundancy issues — implementing the deck system and localStorage tracking
— but fully eliminating near-duplicate quotes would require more experience with
APIs and a better understanding of how to filter and deduplicate dynamic data at
the source level. That's what I'd keep working on with more time.
